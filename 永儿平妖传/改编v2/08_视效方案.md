# 《永儿平妖传》视效方案

版本：v1.0｜依据：`02_改编方案v2.md`（术显本性、奇观阶梯）、`05_分场剧本/`
用途：把剧本里的法术和奇观落成一套统一的视觉规范，交给制作层。每一项核心视效都附 Midjourney 提示词，用来验证材质、颜色、规模和情绪是否成立。
范围：本文件只定"看起来是什么样、为什么这样"，不定镜头和剪辑，那些由制作流程接管。提示词里的构图词只为出验证图，不约束成片。

---

## 一、总原则

1. **一眼认出是谁的术。** 纸是永儿，墨是圣姑姑，泥是左黜，镜光是蛋子和尚，金光是天。任何一帧画面里，观众不用看人就能分清。不同材质不混色，斗法时两种材质的交界要清楚。
2. **怎么坏，就是规则。** 纸遇水变软、遇火成灰、沾污秽就塌；墨遇水晕开；泥被镜光照裂。每种材质被破的方式在第一次出现时就要拍清楚，后面才能回收。
3. **奇观落到一个人身上。** 每场大奇观最后都收到一个人的尺度：一只手、一个炊饼、一张愿纸。验证图里也要出一张"人的尺度"。
4. **代价看得见。** 永儿的纸白是全剧唯一一条持续性的身体视效，进度必须逐集可查（见第四节）。
5. **人间不加特效。** 欠饷、州衙、粥棚、市井一律写实，不调魔幻色。奇观越大，人间越要朴素，两者才有对比。

## 二、色彩与质感基调

| 类别 | 主色 | 质感关键词 | 光 | 不能出现 |

## 三、材质视效规范

每种材质写清五件事：长什么样、怎么动、怎么成形、怎么被破、不能做成什么样。每种材质先跑一组"材质基准图"，通过之后再跑逐集视效。

### M-01 纸（胡永儿）

- **外观**：本色毛边纸、竹纸、桑皮纸。能看到纤维和折痕，薄处透光。纸人、纸兽的骨架是竹篾，关节处能看到糨糊和纸绳。
- **运动**：轻，有风感，会飘、会翻、会抖。活过来的纸扎动作带一点"纸的僵"：关节一折一折，不是肉的弯曲。成群时像鸟群或雪。
- **成形**：碎纸从各处飞来，一片片贴合、折叠成形，像有一双看不见的手在扎。
- **被破**：遇水先软、再塌、最后泡成纸浆；遇火从边缘卷黑、成灰、往上飘；沾血或秽物，从沾上的地方开始往下瘫。
- **禁忌**：不能像折纸艺术品那样精致锋利；不能有塑料光泽；纸兵不能像盔甲兵。

### M-02 水墨（圣姑姑）

- **外观**：真的墨，不是黑烟。有浓淡、有飞白、有湿边，悬在空中时像画在一张看不见的宣纸上。
- **运动**：像墨滴进水里那样晕开、舒展，再收成形。笔势感强：先有一笔，再有一个东西。
- **成形**：圣姑姑凌空运笔，墨线落下的地方，东西就"画"出来了（墨蝶、墨狐、墨山、墨色幻象）。
- **被破**：遇水晕散成一团灰雾；被天兵金光烧穿时，墨像纸被烫穿一样卷边，留下焦黄的洞。
- **禁忌**：不能做成黑色烟雾或粒子；不能有实心无层次的黑。

### M-03 泥（左黜）

- **外观**：黑褐色烂泥，夹着腐草、碎骨、虫壳，表面湿亮。泥鬼没有五官，只有两个凹下去的坑。
- **运动**：从地里拱出来，笨重、拖沓，往下滴泥。抓住东西时会"糊"上去。
- **成形**：左黜拐杖一顿，地面拱起土包，泥鬼从土包里爬出。
- **被破**：镜光一照，表面泥壳干裂、成块剥落，露出里面的东西（EP23 露出瘸腿的狐尸）。
- **禁忌**：不能像熔岩、不能发光、不能像丧尸。

### M-04 镜光（蛋子和尚／诸葛遂智）

- **外观**：从一面旧铜镜里射出的冷银光。光是锐利的一束，照到哪里，哪里的幻术就现出本相。
- **运动**：直、快、有方向。化作大鸟时，鸟是由无数镜面碎光拼成的，翅膀扇动时光斑在地上乱跳。
- **禁忌**：不能是彩色、不能是粒子烟花、不能像激光武器。

```

### M-05 金光天雷（九天玄女与天兵）

- **外观**：赤金和炽白，带熔铸感。天兵是金光勾出的轮廓，看不清脸。天雷是从天空裂缝里倒灌下来的。
- **运动**：压倒性的，从上往下，一层层烧穿。
- **禁忌**：不能像佛光、不能柔和、不能卡通。

```

### M-06 污秽（猪羊血）

- **外观**：暗红偏褐、稠，像泼出来的，不是喷溅。下成雨时偏暗、偏浊。
- **作用**：只用来破纸。纸沾上就从那一点开始瘫软、发黑。

## 四、持续性视效（跨集）

### C-01 永儿的纸白

全剧唯一一条持续性身体视效。纸白不是"变白"，是皮肤变成纸的质感：失去血色、出现细纤维和折痕感、边缘像毛边纸。她摸东西时感觉不到温度。

| 集 | 范围 | 剧本依据 | 状态 |
|---|---|---|---|
| EP01–13 | 无 | 只有左手腕一小片灰色胎记 | 正常 |
| EP14 | 指尖 | 结尾她低头：指尖开始发白 | 出现 |
| EP15 | 指尖 | 炊饼不觉得烫；把指尖往袖里藏 | 扩大中 |
| EP18 | 指尖到指节 | 感觉不到孩子的手 | 扩大中 |
| EP19 | 手背，结尾漫过手腕 | 婴儿碰到她的手哭得更凶 | 扩大中 |
| EP21 | 手腕以上 | 握剑时看见；撤封城纸兵后指尖微温 | 最严重 |
| EP22 | 手腕，边缘退一线 | 露出一圈淡淡的血色 | 开始消退 |
| EP23 | 从手腕退到指节 | 撤去满城法术 | 消退中 |
| EP24 | 指尖残留，最后退尽 | 炊饼烫得指尖发红，最后一点纸白退下去 | 消失 |

## 六、逐集核心视效

按 `02_改编方案v2.md` 奇观阶梯逐集列出。EP11、EP16 是现实戏，没有奇观，不列。每条写清验证要点，出图时按要点逐条打勾。

### S-01 EP01 降生之夜

## 七、验证流程

1. **先跑材质基准**（第三节 M-01 到 M-06）。六种材质都通过，再跑逐集视效。材质不通过就调第二节的色彩和质感，而不是在逐集提示词里打补丁。
2. **定风格参考图**。从通过的材质基准图里各选一张，作为后续同材质提示词的 `--sref`，保证全剧质感一致。
3. **定角色参考图**。永儿、圣姑姑、左黜、王则各出一张定妆图，后续出图用角色参考（v7 为 `--oref`）锁脸。
4. **逐条跑逐集视效**。每条至少出一组四张，按"验证要点"打勾。
5. **记录**到下面的表里。通过的图存档，作为交给制作层的参考。

### 判定标准

| 结果 | 含义 |
|---|---|
| 通过 | 验证要点全部满足，可以直接作为制作参考 |
| 待调 | 方向对，某一项要点不满足；在"调整"一栏写清改了哪个词 |
| 不成立 | 多次调整仍出不来，或出来了也不好看；回到剧本层考虑换一个奇观 |

## 八、Midjourney 使用说明

- **参数**：本文件统一使用 `--ar 9:16 --v 7 --style raw`。`--s` 按画面类型分三档：特写和道具 100–150，常规场面 200–250，大奇观 300–350。换用更新版本时，把 `--v` 改掉即可，提示词正文不用动。
- **写实锚词**：每条都带 `live-action cinematic still, photoreal`，防止出插画或游戏原画风。如果画风仍偏插画，可再加 `35mm film photograph`。
- **一致性**：同材质用 `--sref` 指向已通过的材质基准图；同角色用角色参考图锁脸。
- **敏感词替换**：MJ 会拦截部分词，统一按下表替换，不影响画面判断。

| 原意 | 写法 |
|---|---|
| 血、血雨 | `dark crimson rain`、`thick dark red liquid` |
| 尸体 | `lifeless body` |
| 斩首、杀 | 不出图，剧本里这类戏只拍前后 |

- **出不来时先查什么**：
  1. 材质混了：给每种材质加颜色限定词（`off-white paper`、`black ink`、`black-brown mud`、`cold silver light`）。
  2. 规模不够：加 `colossal`、`thousands of`、`above an ancient walled city`，并把 `--s` 提一档。
  3. 太像插画：删掉形容美感的词，加 `photoreal`、`film grain`，`--s` 降一档。
