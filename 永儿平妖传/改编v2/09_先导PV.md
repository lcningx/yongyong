# 《永儿平妖传》先导 PV

版本：v1.0｜依据：`02_改编方案v2.md`、`05_分场剧本/`、`08_视效方案.md`
规格：竖屏 9:16；正片 60 秒，另附 15 秒短版；投放平台抖音
用途：开播前预热。让没看过剧的人在 3 秒内停下来，在 60 秒里记住三件事：她扎的纸会活；满城人把她当神；当神是有代价的。

本文件只定"放什么、说什么、听见什么、按什么顺序"，不定镜头和剪辑手法，那些由制作流程接管。画面编号对应 `08_视效方案.md`，PV 专用的画面另附 MJ 提示词（第六节）。

---

## 一、核心设计

**一句话**：一个纸扎铺的女儿，扎的纸会活；后来满城人跪她为神，而神是纸做的。

**情绪曲线**：好奇 → 惊喜 → 心动 → 狂热 → 静 → 崩 → 一句话收住。

**声音主线**：全片的节奏点用纸的声音打，不用鼓。前半段是折纸、翻纸的轻响，狂热段落是万人呼声和大乐，最后崩塌时，每一下重拍都换成一声撕纸。观众听完会记住"纸"这个声音。

**三条台词原则**：
1. 只用剧本里原有的台词，PV 不另写台词。
2. 每句台词都不交代上下文，只留情绪。
3. 字幕总共不超过四行，其余交给画面。

## 二、剧透红线

以下内容 PV 里一律不出现，它们是正片的反转和付费卡点：

| 不出现 | 原因 |
|---|---|
| 断尾白狐、驼背即断尾 | EP21 反转：圣姑姑的真身 |
| 箭羽上的狐毛、射箭的人 | EP07 付费卡点和 EP21 反转：杀憨哥的是左黜 |
| 泥壳下的狐尸 | EP23 左黜本相 |
| 墨画前世、"你是媚儿" | EP20 揭晓 |
| 憨哥中箭、王则被擒、永儿之死 | 情感结局 |
| 纸刀落在母亲身上 | EP18 结尾，太重，也会让人误判这部剧的调性 |

可以出现、但不交代因果的：天兵金光、天空被撕开、"这一回，我自己选"。观众看得到结局的规模，猜不到结局本身。

## 五、声音设计

| 段落 | 音乐 | 音效 | 人声 |
|---|---|---|---|
| 钩子、来历 | 无 → 一个低音长音 | 折纸、纸灰飘动的沙沙声 | 童谣，孩子的声音要干、不加混响，带一点诡异 |
| 学术、人间 | 箫，旋律轻，带一点笑意 | 纸虎落在瓦上的纸声 | 圣姑姑温和、慢；憨哥高兴、笨拙 |
| 遇则 | 乐声变低，弦乐垫底 | 城头风声 | 永儿很轻，像只说给一个人听 |
| 成神 | 全编制推到最高，人声合唱 | 愿纸成群飞起的哗哗声 | 万人呼喊，越喊越整齐 |
| 静 | 全停 | 只剩风、凤冠珠串的轻响 | 圣姑姑的回声，远而清楚 |
| 崩 | 不用音乐，只用撕纸声作重拍 | 撕纸声由轻到重，四下 | 马遂沙哑、疲惫，不是指责 |
| 收、片名 | 一声撕纸后全静 | 片名出现时一声折纸 | 永儿平静，不哭不喊 |

**配音选角提示**：永儿这条 PV 只有两句话，"你在哪，我在哪"要软，"这一回，我自己选"要稳。同一个人，两种状态，观众要听得出她变了。

## 七、发布文案

**标题备选**：
1. 她扎的纸会活。后来，满城人跪她为神。
2. 纸灰里生下来的姑娘，扎什么，活什么。
3. 神，是纸做的。

**简介**：
> 北宋汴京，纸扎铺的女儿胡永儿，扎的纸会活。她用纸虎让爹娘吃饱，用纸鹤逃离人间，用十万纸兵守住一座城。满城人跪她为"圣女"，可她的手，一天比一天像纸。改编自明代神魔小说《三遂平妖传》。
