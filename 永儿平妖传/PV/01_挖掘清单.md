## 2. 世界异常点

- 烧给神佛的纸灰不往下落，立起来绕过院墙往产房窗缝里钻（EP01）
- 画中美人眼珠会转、"像要走下来"；画遇火腾起青蓝色火苗，纸灰往人衣襟口鼻里钻（EP02）
- 水泼上火墙，火苗反而窜得更高（EP04）
- 枯枝插地喝声"长"，转眼满树开花；石头变银子、落地又变回石头（EP05）
- 长凳念咒化虎、驮人腾空飞天（EP06/EP09）
- 纸人落地干活、空米缸米汩汩涌上来（EP06/EP07）
- 泥烛火里能看见前世幻象（EP11/EP13）
- 纸兵豆马成片涌出冲阵，被僧人泼秽物噗噗瘫回纸屑豆子（EP21）
- 九天雷火自云端追"妖"而至（EP24）

## 3. 人物欲望

**胡永儿**
- 外在：养家活命（EP05–06）→ 护住追随她的百姓（EP15–24）→ 最后一回自己做主（EP24）
- 内在：**"从来没人问过我愿不愿意"**（EP01 开场白）——一生要的就是一次"自己选"（EP24"这辈子——我自己选一回"，与 EP01 逐字闭环）
- 隐含渴望：被当作"人"而不是"妖种/圣女/棋子"对待（EP03 捡铜钱、EP08 憨哥、EP17 扶跪民）

**王则**（副线）
- 被正眼看一次（EP13"满贝州谁拿正眼瞧过我王则"）→ 让弟兄吃饱饭 → 被"天命"套牢，念咒般自语"天命在孤"（EP20）

## 4. 升级链素材（危险逐层变严重）

1. 出生带纸灰异象，被全城叫"妖种"，铜钱被扔在地上（EP01–03）
2. 天火烧光家产，父亲怕她，骗她进道观泼符水、亲手推她下河（EP04–07）
3. 唯一对她好的丈夫憨哥替她中箭而死，她被当众殴打（EP09）
4. 入局贝州：起义、开仓、称王，万人跪喊"圣女娘娘"（EP13–18）
5. 变质：王则默许搜粮杀降，夫妻隔墙（EP19–21）；马遂碎牙、悬尸城门（EP22）
6. 发现自己从出生起就是圣姑姑写好的局："我这一辈子，从娘胎里就是你写的剧本"（EP23）
7. 城破之夜：遁符在袖（生路一条），雷火在顶（死路一条），百姓在城门（EP24）

## 5. 未回答的问题

- 纸灰聚成的"像花又像字"的花纹是什么？她到底从哪来？（EP01 埋下，全剧未正面答）
- 驼背老妇/圣姑姑究竟是谁？为什么偏偏选中她？
- 转世之说是真是假？（剧本附注：不证实不证伪，作为权力叙事处理）
- 圣姑姑被押走前无声念的两个字是什么？（EP23）
- 雷火劈下画面一白——她死了吗？（EP24）
- 次年市集接饼的驼背老妇是谁？"没有人知道她是谁"（EP24）
- 蛋子和尚"术……可以不用"是什么意思？他最后去了哪？

## 6. 贯穿声音候选（可三次变奏重复）

| 候选 | 变奏素材 |
|---|---|
| **"愿不愿意"一句** | ①EP01"我这辈子……从来没人问过我愿不愿意"（自述）→ ②EP23"你问过我，愿不愿意吗？"（质问）→ ③EP24"这辈子——我自己选一回"（回答）。同一句完成"疑问→质问→自答"三级升级 |
| **"饼，你吃，别饿"** | ①EP08 憨哥焐热饼"你吃"→ ②EP09 临死"饼……你吃……别饿"→ ③EP24 孩子"娘娘……饼，你吃。别饿"。同一句话跨生死、跨两代人传回来 |
| **纸兵关节咯吱声/纸屑簌簌声** | EP01 城头纸兵关节作响 → EP21 纸兵瘫软噗噗 → EP24 漫天纸雪簌簌 |
| **"疾！"** | EP06 第一次骑虎的惊喜 → EP09 含着眼泪的厉声"疾！" |
| **童谣"胡家女，纸灰胎"** | EP03 孩童起哄唱（目前只出现一次，变奏需创作） |

## 7. 不可泄露的秘密（PV 全片不得揭晓）

- **EP23 底的揭晓**：仙画、天火、父惧全是圣姑姑蓄意布局，"从娘胎里就是你写的剧本"——PV 可以暗示"她的一生被人安排"，但不得揭晓布局全貌、不得出现圣姑姑认罪对白
- **EP24 结局**：她拒遁、撤术、雷火一白之后发生什么——绝不展示
- **次年驼背老妇的身份**——绝不点破
- 圣姑姑被擒前无声的两个字
- 王则凌迟的结局（剧本 EP24 旁白内容，PV 不交代各人下场）
