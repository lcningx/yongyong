# 02 · PV 创意纲领 ——《永儿平妖传》情绪PV

> 一页锁定。已通过确认门（2026-10-12）：情绪PV / "愿不愿意"三变奏 / 攥遁符断崖 / 驼背老妇尾钩 / 90秒 / 9:16竖屏。

- **PV 类型**：情绪PV
- **核心卖点（一句话）**：生来被叫"妖"的女孩，一生都是别人写好的局——最后一回，她自己选。
- **观众看完必须记住的画面**：漫天纸雪落在她肩上发上，她松开手，任一张黄符飘落。
- **情绪曲线（七段）**：纸兵城头的诡异 → 妖种童年的怜惜 → 枯枝开花的惊奇 → 失去与跪拜的加速眩晕 → 握着生路的全场死寂 → 纸雪雷火的爆发 → 一块炊饼递回来的余震。
- **不可泄露的真相**：① 仙画、天火、父惧全是圣姑姑布的局（EP23，PV 只出现残画与一句质问，不揭全貌、不出现认罪对白）；② 雷火一白之后她的结局（EP24）；③ 次年驼背老妇是谁——"没有人知道她是谁"，全片不点破。
- **结尾留下的问题**：她到底是不是妖？她最后选了什么？——观众不需要明白故事，但必须想知道答案。
